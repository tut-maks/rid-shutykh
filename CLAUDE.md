# Рід Шутих — нотатки для розробки

- Мова інтерфейсу і відповідей — українська. Власник — Максим, не розробник: пояснювати просто, покроково.
- **Безпека понад усе (вимога власника):** браузер ніколи не звертається до Supabase напряму, жодних ключів на сторінці. Усе — через `api/*.js` з перевіркою сесії (`handler()` у `_lib.js`). Нові таблиці — тільки з `enable/force row level security` і `revoke all from anon, authenticated`. Файли — лише через `/api/file`.
- Кожна зміна даних → `revision()` (що було → що стало). Кожна дія перегляду → `track()` / `/api/track`.
- Ролі: `owner` > `editor` > `viewer`. Спогади можуть додавати всі, картки — редактор і вище, видаляти картки — лише власник.
- Інтерфейс: ванільний JS (`public/app.js`), стан `S`, `render()` перебудовує `#app`. Без збірки, без бібліотек. CSP: скрипти лише `'self'`, без inline-скриптів і inline-обробників.
- Стиль: світлий, мінімальний, «архівний» (білий аркуш, чорнило, тонкі лінійки, Old Standard TT для імен). Один світлий вигляд.
- Статистика для власника — максимально розгорнута: періоди (готові й свій), порівняння з попереднім періодом, сортування колонок, журнал по кожному родичу.
- Перевіряти на 1440 px і 390 px. Локально: `npm run dev` (мок-база).
- Дані досліджень (люди, документи) — у `seed/seed.json`; після запуску сайту зміни вносяться через інтерфейс, не через seed.
