# Пам'ять перевірок «навиворіт» (19.10.2026)
- `LESSONS.md` — правила сліпого читання скану; `CHAIN.md` — ланцюгові проходи вгору/вниз; `ADJUDICATE.md` — правила суддів.
- `readings.jsonl` — сліпі прочитання 668 документів (до 1925 р.): помічник бачив лише вирізку скану з рамкою, без тексту сайту. Наступне коло: документи, що тут є, наосліп повторно не читати (хіба змінився скан чи рамка).
- `chain.jsonl` — вердикти ланцюгових проходів: UP (від наймолодших до найдавніших, з боку дитини) і DN (від найдавніших униз, усі діти батька разом).
- `verdicts.jsonl` — вердикти суддів (ERROR/HYP/OK/SCAN) і застосовані патчі (ключі `au19x-*` у manifest).
- Ролі міняти щоразу: читачі — за епохами (не за гілками), судді — інші помічники, ніж ті, що знайшли.
