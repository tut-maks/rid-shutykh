- **Козацьке, 1894, № 41:** Павел, 28/29.06.1894, батьки — «села Козацкого собственник Григорий Марков Терещенко и законная жена Зиновія Павлова». Козацьке — сусіднє з Вороньками село. Файл fs_tereshch_pavlo_1894.jpg.

**Що далі:** переглянути книги Козацького (Терещенки 1880–1920), а також Вороньків 1918–1923 за прізвищем; спитати Василя Віталійовича, про кого саме казали «Терещенко».
